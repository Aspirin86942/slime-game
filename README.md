# 史莱姆 · 家园

双击根目录的 [史莱姆.html](史莱姆.html) 即可游玩。页面、素材和游戏规则都在一个文件中，可离线运行。

陪伴、召唤、探索、背包和成长沿用 ae243d9 的界面及玩法。底部新增家园入口，默认进入陪伴。接球、叠叠乐也可以从家园的玩具区进入。

## 家园

家园是一张铺满窗口的36×24格连续地图。地面采用俯视布局，建筑立面、屋顶、阴影和前后遮挡呈现立体感。

- 拖动空地移动视野；滚轮或右下角按钮缩放。手机支持单指拖动和双指缩放。
- 点击「建造」，选择设施或装饰，再点空地放置。支持旋转、移动、收纳和取回。
- 在「小径」中选择材质，按住拖动连续铺路。中键、右键或双指可以在铺路时移动视野；取消触摸不会提交半截笔画。
- 「种植」支持播种、照料、收获、育种、命名、收藏、复制留种和自动补种。首次收获会获得一颗发光花种子。
- 「制作」提供厨房、木工、炼制、堆肥和档案馆配方；「生态」显示土地属性与访客条件。
- 点击史莱姆进行互动，点击设施安排空闲伙伴工作。工作、派遣、战斗和小游戏共享占用状态。

24种可经营设施、42件装饰、6种路面、55种植物、17条配方和18种生态访客可用。已有远征站和共鸣石作为纪念装饰保留，可移动和收纳。

## 存档

V1–V4存档首次加载时先备份原始字节，再迁移为V5。伙伴身份、名字、成长、亲密度、珍爱锁、库存、植物品系和制作队列保留。原六个家园区域按三列两行合并，所有建筑、植物和道路使用全局坐标。

新版远行、独立故事、关系、共鸣育幼和三款新增小游戏停止运行。已有旅行物资归入仓库，已获得晶币结清；原记录、幼体和历史关系保存到归档。仓库可查看历史收藏，伙伴面板可查看回忆。原版探索派遣、深渊与教学挑战继续可用。

在线和离线共用同一个推进时钟，离线最多结算12小时。存储失败时保留重试入口；坏档、未知版本和其他标签页更新会停止写入。存档归属当前浏览器及文件地址。

修改前的程序快照在 [backup/史莱姆-20261028-pre-single-home.html](backup/史莱姆-20261028-pre-single-home.html)。旧程序须搭配对应的旧存档备份使用。

## 开发与验证

使用 Node.js 24 或更高版本，在仓库根目录依次运行 npm ci、npm test、npm run test:browser。内容目录由 npm run docs:content 生成。

npm run build 从源码生成史莱姆.html。请修改源码，再构建交付文件。

- src/legacy/：原版玩法与统一时钟、存档桥接。
- src/world/map.ts、home-art.ts、home-view.ts、home.css：地图、绘制和家园界面。
- src/world/engine.ts、life.ts、ecology.ts：经营规则、伙伴行动和生态。
- src/world/migration.ts、storage.ts、inventory.ts：迁移、校验与统一库存。
- tests/home.test.mjs：单地图规则、V1–V4迁移、库存守恒和原生接口。
- tests/home-browser.cjs：独立Chrome配置中的鼠标、触屏、截图、离线重载和帧率检查。

tests/world.test.mjs、common-life.test.mjs保留对V4源格式与规则的覆盖，帮助验证迁移输入；旧版故事/远行浏览器脚本属于历史验收。原始造型基线文件禁止改写。
