# 史莱姆 · 家园

双击根目录的 [史莱姆.html](史莱姆.html) 即可游玩。页面、素材和游戏规则都在一个文件中，可离线运行。

陪伴、召唤、探索、背包和成长沿用 [史莱姆-参考.html](史莱姆-参考.html) 的界面、角色造型和玩法。底部增加家园入口，默认进入陪伴。战斗保留手动／自动模式，探索收益暂存后点击领取；接球、叠叠乐也可以从家园的玩具区进入。

## 家园

家园保留「林间绘本」的手绘建筑、植物、水彩草地和成片树林；界面统一采用参考版魔法风，六种主题会同步应用到全部页面。36×24格连续地图铺满窗口，顶部资源栏和底部导航与原页面保持相同位置、尺寸及线框图标。建造等面板使用当前主题的实色背景，素材已内嵌，离线打开也能完整显示。

- 拖动空地移动视野；滚轮或右下角按钮缩放。手机支持单指拖动和双指缩放。
- 点击「建造」，选择设施或装饰，再点空地放置。支持旋转、移动、收纳和取回。
- 在「小径」中选择材质，按住拖动连续铺路。中键、右键或双指可以在铺路时移动视野；取消触摸不会提交半截笔画。
- 「种植」支持播种、照料、收获、育种、命名、收藏、复制留种和自动补种。首次收获会获得一颗发光花种子。
- 「更多」中可打开制作、仓库和生态。制作提供厨房、木工、炼制、堆肥和档案馆配方；生态显示土地属性与访客条件。
- 点击史莱姆进行互动，点击设施安排空闲伙伴工作。工作、派遣、战斗和小游戏共享占用状态。

24种可经营设施、42件装饰、6种路面、55种植物、17条配方和18种生态访客可用。已有远征站和共鸣石作为纪念装饰保留，可移动和收纳。

## 存档

V1–V4存档首次加载时先备份原始字节，再迁移为V5。伙伴身份、名字、成长、亲密度、珍爱锁、库存、植物品系和制作队列保留。原六个家园区域按三列两行合并，所有建筑、植物和道路使用全局坐标。

新版远行、独立故事、关系、共鸣育幼和三款新增小游戏停止运行。已有旅行物资归入仓库，已获得晶币结清；原记录、幼体和历史关系保存到归档。仓库可查看历史收藏，伙伴面板可查看回忆。原版探索派遣、深渊与教学挑战继续可用。

在线由一个时钟协调原版每秒恢复、每12秒探索和家园推进。离线仅补算家园，最多12小时，原版体力、饲料和探索奖励不额外推进。存储失败时保留重试入口；坏档、未知版本和其他标签页更新会停止写入。存档归属当前浏览器及文件地址。

本次修改前的源码、测试、构建配置和成品快照在 [backup/reference-home-20261029-implementation/](backup/reference-home-20261029-implementation/)，其中 snapshot.json 记录每个文件的 SHA-256。恢复时使用同一套源码和成品，并搭配对应的旧存档备份。参考文件保持只读，原始内容未修改。

## 开发与验证

使用 Node.js 24 或更高版本，在仓库根目录依次运行 npm ci、npm test、npm run test:browser。内容目录由 npm run docs:content 生成。

npm run build 从源码生成史莱姆.html。请修改源码，再构建交付文件。

- src/legacy/：原版玩法与统一时钟、存档桥接。
- src/world/map.ts、home-art.ts、home-view.ts、home.css：地图、绘制和家园界面。
- src/world/art/storybook.ts、src/assets/storybook/：绘本素材映射与离线资源；生产源图和处理流程见 [林间绘本美术说明](docs/art-2026-10-29/README.md)。
- src/world/engine.ts、life.ts、ecology.ts：经营规则、伙伴行动和生态。
- src/world/migration.ts、storage.ts、inventory.ts：迁移、校验与统一库存。
- tests/home.test.mjs：单地图规则、V1–V4迁移、库存守恒和原生接口。
- tests/home-browser.cjs：独立Chrome配置中的鼠标、触屏、截图、离线重载和帧率检查。
- tests/reference-home.test.cjs：参考版界面与数值对照、真实V2存档、共享库存、离线边界和旧珍爱锁兼容。
- tests/reference-browser.cjs：五种视口逐页对照参考版，验证家园样式退出、地图事件释放及召唤、领取、战斗和设置操作。
- tests/theme-browser.cjs：六种主题、五种视口与三种安全区高度的组合检查，覆盖共用栏位、面板、控件遮挡、主题切换、减少动画和刷新恢复。

tests/world.test.mjs、common-life.test.mjs保留对V4源格式与规则的覆盖，帮助验证迁移输入；旧版故事/远行浏览器脚本属于历史验收。参考文件与历史造型基线均禁止改写；本次外观断言使用参考文件。当前浏览器截图与结果保存在 tools/out/magic-ui/，原接入验收保留在 tools/out/reference-home/。魔法风统一前的源码与成品快照在 backup/magic-ui-20261029/。
