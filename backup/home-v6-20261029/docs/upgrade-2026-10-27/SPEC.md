# 史莱姆牧场升级 SPEC

> 游戏性更新：战斗公式、首领、经济、离线收益与保底以 [数值设计](../gameplay-2026-10-27/数值设计.md) 为准。本文其余部分保留原升级包的界面与交互规格。

## 范围与不变约束
- 基于 `original.html` 升级单文件离线游戏，不依赖网络/CDN，不覆盖原始备份。
- **不改变史莱姆现有形状、配色、表情或元素设定**；不新增元素或无关系统。
- 保留随机战斗、自动/插手/单步模式、小游戏、互动和已有存档；旧存档只作安全补齐，不暗中删除或下调已有属性。

## 验收标准
### A. 核心经济与安全迁移（P0）
1. 胜利结算全部敌人收益；失败只按实际击败敌人发放部分收益。未击败敌人则零金币/经验。统计存活者必须发生在战后恢复之前，仍保留战后恢复。
2. 深渊从已解锁层数开始，胜利逐层解锁；不能选择未解锁的 50 层送死刷奖励。旧进度按可靠胜利记录兼容，不因旧已拥有宠物而清档。
3. 派遣体力不足当次行动成本时进入休息，不会卡在 1–19；恢复进度与继续行动门槛可见，并在达到门槛后恢复。
4. 升级和融合使用统一属性公式；融合明确收费、确定性预览和随机项概率。旧宠物属性不被回溯削弱。
5. 存档增加版本和一次性迁移备份、导出入口；坏数据不会自动覆盖可恢复的旧数据。

### B. 战斗可读性与决策
1. 单位随队伍规模调整；名字、生命条清晰，行动者/我方选择/敌方目标区分，状态显示图标和层数。
2. 敌方下回合意图来自真正锁定的行动；行动执行遵从该意图，目标死亡等例外会重新说明；控制可以阻止预告行动。
3. 新增三场可执行固定教学挑战，分别提供护盾、控制、净化的决策机会；保留随机战斗，并加入首次通关、区域探索、收集目标及可领取奖励。
4. 普通攻击反馈克制；暴击/重要技能明显更强，避免所有攻击同等闪烁。

### C. 陪伴与身份
1. 默认首页是陪伴空间，展示当前目标和探索入口；主题选择移到设置。
2. 打开空间、滚球、叠叠乐不暂停已派遣队伍；保留宠物闲置互动。
3. 融合保留主宠 ID、名字、亲密度等身份；预览说明继承/变异/损失/金币成本；可锁定珍爱宠物，锁定副宠不可被消耗。
4. 亲密度里程碑解锁可见回应/现有表情变化/装饰徽章，不要求强制战斗。

### D. 视觉与离线
1. 操作图标统一使用本地 SVG 或一致图标风格；史莱姆绘制函数不重做。
2. 场景加入轻量树木、洞窟、遗迹等地标层次，各区域不再只是换色。
3. 所有改动保持单 HTML 可双击离线运行；不引入远程素材。

## 验证与交付
- 交付升级 HTML、SPEC、PLAN、测试记录。
- 运行 JavaScript 语法检查、原有自测和新增确定性回归（结算、解锁、体力恢复、融合、迁移、意图/控制/教学/目标）。
- 浏览器检查实际能力允许时执行；未执行的浏览器/视觉验收明确列为限制，不冒称通过。

## 已确定的规则数值（实施前补充）
- 战斗结算基准：每只敌人经验为 `round((30 + 敌人等级×10) × (1 + (本场深渊层数−1)×0.25))`。胜利按全部敌人计算；失败仅对本场 HP≤0 的敌人求和，再取 `floor(总和×25%)`。金币为 `round(结算经验×2.5)`；零击败即零奖励。
- 经验接收者按恢复前的存活名单快照决定；若全灭，则由实际参战的全部伙伴平分已挣得的部分经验；零经验不调用成长函数，避免凭空获得召唤师经验。训练战不产生普通金币/经验、捕捉或深渊解锁。
- 深渊默认解锁第 1 层。赢得第 N 层后解锁 `min(50,N+1)`，入口、加减按钮、输入框均受锁层限制，结算使用开战时的层数快照。旧版任意可选层数不是胜利证据，旧档保留宠物/金钱/属性并备份，选择层数回落至有胜利记录支持的已解锁上限。
- 探险每次仍耗 20 体力；体力不足 20 或心情≤0 即休息。恢复阈值为 `max(20,ceil(最大体力×50%))` 且心情≥50；休息期间每秒体力恢复 `0.4×(1+体力词条)`、心情恢复 0.1，饲料槽机制保留。达到阈值自动续行。打开空间或小游戏不暂停派遣队伍。
- 存档版本为 2；首次迁移前保留原始 JSON 到独立备份键，迁移可重复执行且不重置已有奖励/锁定/进度。解析或结构校验失败时阻止写入主存档，提供原文导出与合法 JSON 导入恢复；不会以新游戏默认值覆盖坏档。

## 融合与成长的具体规则（实施前确定）
- 力/敏/魔统一基准：`G(潜力, 等级) = 潜力 + (等级 − 1) × round(潜力 / 2)`。
- 升级或融合只给当前属性增加 `max(0, G(新潜力, 新等级) − G(旧潜力, 旧等级))`。不重算覆盖旧属性，因此旧版融合获得的额外数值保留；相同潜力、等级重复融合不会凭空翻倍。经验可连续升级，零经验不产生召唤师经验。
- 融合费：`500 + 100 × max(双方等级) + 250 × 主宠已融合次数 × (主宠已融合次数 + 1)` 晶币；1 级主宠首次 600、第二次 1100。费用随连续融合上升，免费召唤不再等于免费强化。
- 确定继承：主宠 ID、名字、性格、善恶、亲密度、经验、珍爱锁、定制规划、已获得属性；等级取双方较高值。主宠心情、体力不因融合刷新。副宠永久消失（含未继承经验、亲密度、词条和规划），消耗前在预览列出。
- 潜力：75% 不变，25% 为三项潜力同时 +1/+2/+3（等概率，上限 40）；触发时幸运/悟性 +1（上限 20）。同名词条加成确定提高 20%；不同词条按副宠顺序，各有 50% 概率继承，最多 3 条。主宠原词条不会丢失。
- 元素：同元素保持；不同元素为 80% 主元素、18% 副元素、2% 从草/冰/雷/幻/光/暗/空间/时间均匀抽取（该池可能与双方元素重合）。体型 90% 不变、10% 增加 `副宠体型 × 0.008`。
- 珍爱锁默认未锁：锁定宠物可作为保留的主宠，不能作为被消耗的副宠；选择、预览及最终执行均校验。新字段 `locked: false`、`mergeCount: 0` 可安全补齐，不需重置旧宠物。

## 战斗教学与长期目标的确定规则
- 三场训练随时可进入，使用临时借用伙伴和固定敌人，不消耗/改变真实伙伴，不提供常规战斗经验/晶币，不可捕捉；保留战斗模式切换，但默认逐回合。
- 护盾训练：借用岩伙伴 320 HP；首回合敌人预告 320 固定伤害，之后 60。初始无护盾，需用磐石落获得 30% 最大 HP 护盾。必须实际用护盾吸收重击并胜利才记通关。
- 控制训练：借用幻伙伴 300 HP；首回合和每三回合预告 400 固定重击，其余 60。必须用控制取消一次已预告重击并胜利才记通关。
- 净化训练：借用光伙伴 300 HP；开场各 3 层烧伤/中毒，敌方固定 35 伤害。必须净化实际存在的负面并胜利才记通关。训练伤害不产生随机闪避/暴击；主动技沿用原技能。
- 每场训练首次达标：可手动领取 300 晶币 + 5 积分；重复训练没有收益。普通深渊首次胜利：400 晶币 + 5 积分。
- 每个区域成功完成 3 次派遣行动，全部 3 区域完成后可领 600 晶币 + 2 天材地宝。拥有过 6 种元素可领 800 晶币 + 10 积分，记录收集不因融合失去。
- 目标奖励均独立一次性领取，重复点击无收益。旧存档已拥有元素可计入收集；无法证明的历史通关/探索不凭空补发。
- 敌方每回合开始前锁定实际行动及目标：攻击、每 3 回合重击（1.65×）、低血量防御或治疗；目标失效时明确重新锁定，控制将预告标为取消。战斗解决中不允许定时器重入下一回合。

- 融合预览期间若派遣使选中宠物的等级、潜力或费用相关信息变化，先更新预览并要求再次确认，不按过期预览扣费。
- 正常开场未完成（`started:false`）也是合法存档；加载后继续开场，不锁写、不重复发奖励。导入采用事务：新档验证/迁移/写入失败时恢复旧主存档与运行态，并提供“导入前备份”导出。
- 奖励账本保留本场全部初始敌人，即便战斗中已捕捉并移出场景也不漏算；捕捉本身不重复结算。休息恢复每 10 秒保存一次，跨重载保留进度。

### 陪伴与界面实现细则
- 首页默认进入陪伴空间；成长/召唤/探索/背包入口保留，主题统一位于设置。
- 亲密里程碑：5「熟悉」沿用跟随手指互动；15「信赖」使用原有跳跃表情与新回应；30「挚友」增加原有喜欢表情回应、空间对白与独立心形徽章。徽章在史莱姆容器外部，不改身体或眼睛。
- 抚摸每只伙伴每 30 秒最多增加 1 亲密度，心情互动保持原功能；滚球、叠叠乐的既有亲密收益保留。不强制参与战斗。
- 战斗名字、生命数值、状态图标/层数分离；状态超出单位宽度可横向查看，敌方完整行动/目标保留顶部意图区。少人数队伍放大，多人数缩小；短屏优先保留操作区。
- 普通攻击仅轻量单粒子和轻微命中变亮，不震屏；主动技能沿用重要特效，暴击保留明显反馈。
- 三张原地图使用内置矢量景物：草原树木/路牌、黄昏遗迹/落日、雪原山峰/冰洞。没有远程素材依赖。
