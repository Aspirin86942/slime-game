# 史莱姆牧场 · 升级修复版

## 打开游戏
直接用浏览器打开 `index.html`，无需安装、联网或服务器。

**有旧进度时：**先保留原 HTML 副本，再用修复版替换原路径的游戏文件，并使用原来的浏览器。不同浏览器、隐私模式或不同本地文件地址可能隔离存档；不要删除旧文件或清理浏览器数据。设置中可导出当前存档、升级前备份、导入前备份和浏览器原始数据，也可导入 JSON。

升级只补齐新字段，不清空宠物、金币、已获得属性。旧版可任意选择的深渊层数不是通关记录，因此无可靠胜利记录时从第 1 层逐层解锁；原有宠物和资源保留。首次迁移前自动保存独立原始备份。发现坏档时停止写入，避免用空白进度覆盖。

## 这次改变了什么
- **保留原史莱姆美术：**没有元素造型重设计；原身体、眼睛、配色和表情绘制保留。
- **结算正确：**胜利全额，失败只给已击败敌人 25% 收益，零击败零收益；战后仍恢复伙伴。
- **探险不停摆：**体力不足 20 进入休息，达到半体力且心情 50 后自动续行；空间和小游戏不暂停派遣。
- **融合可预见：**统一成长、明确收费与概率预览，保留主宠名字/身份/亲密度/经验；珍爱锁保护副宠不被消耗。旧属性不回溯削弱。
- **战斗有决策：**真正锁定的敌人意图，控制可打断；三场借用伙伴教学分别练护盾、控制、净化。首胜、区域、收集目标可领取一次性奖励。
- **更像陪伴空间：**默认陪伴首页、亲密度里程碑、统一界面图标、地图地标，以及更清晰的战斗名字、生命、状态和目标层级。
