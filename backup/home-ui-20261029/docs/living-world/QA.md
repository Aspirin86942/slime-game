## 手机家园顶部遮挡修复

手机端按资源栏、季节条、材料栏和工具栏的实际边界计算地图可见区域。地图可以继续拖动，把最上排地块、树冠和屋顶移到无遮挡的位置；回到小屋会同时容纳屋顶、烟囱和入口。横竖屏切换时保持观察位置，聚焦小屋时自动适配可用空间，保留玩家主动选择的缩放比例。安全区改变时监听含内边距的栏位尺寸。
