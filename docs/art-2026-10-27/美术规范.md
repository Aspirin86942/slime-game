# 家园美术规范 · 冷光菌洞

家园使用**冷光菌洞**风格：湿蓝灰岩壁、深色地底木、紫色荧光菌与冷白晶簇。场景没有日光，全部照明来自发光菌、晶体折射与琥珀地脉。奶油纸与苔绿草地的林间绘本风格已整体退役，幽暗地域现在是全游戏唯一的画风基准：家园、六个页面、战斗界面与面板共用同一套 `--lw-*` 色彩语义。

原史莱姆形体、表情与元素样式仍按 `史莱姆-参考.html` 冻结，不改。

## 色彩语义

唯一色源是 `src/world/home.css` 顶部的 `#app` 基础块；六套主题只覆写需要变化的 `--lw-*`，界面变量一律取别名，不再直接写色值。

| token | 值 | 用途 |
| --- | --- | --- |
| `--lw-rock` | `#2f4a52` | 岩体主色 |
| `--lw-rock-dark` | `#1b2f38` | 岩体暗面、夜间压色目标 |
| `--lw-rock-light` | `#4a6b73` | 岩体受光面、建筑受光边 |
| `--lw-moss` | `#4c6b4a` | 洞穴苔藓 |
| `--lw-spore` | `#8f6bb5` | 紫色荧菌：可交互、发光语义 |
| `--lw-crystal` | `#9fe3f0` | 冷白晶簇：高价值、稀有语义 |
| `--lw-vein` | `#c8913f` | 琥珀地脉：暖光、安全语义 |
| `--lw-ink` | `#121c24` | 最深底色，`--surface-solid` 由它派生 |

规则：同屏主色不超过 4 组。三个语义槽稳定不随季节翻转——紫荧菌=可交互/发光，琥珀地脉=暖光/安全，冷白晶簇=高价值/稀有。

六套主题保留原有 `id`（存档兼容，`S.theme` 字段不变），只把配色重配为菌洞同族：`sunset` 深窟、`dark` 幽紫、`light` 浅岩（唯一浅色高对比，供强光环境）、`peach` 矿脉、`mint` 苔沼、`lavender` 霜洞。`light` 与 `mint` 的正文对比度实测 13.0:1 与 14.1:1，深色四主题的墨色—岩色亮度差实测 0.047–0.054，夜间仍能靠亮度差分辨道路与建筑轮廓。

## 坐标与层次

- 地图为 36×24 格，一格 48×48 像素，物件高度向屏幕上方延伸。
- `home-art.ts` 按落地点的 y 坐标排序建筑、植物、伙伴与背景植被。伙伴每秒更新位置与层次。
- 设施升到 2、3 级时换成新形态并扩大占地。占地由 `Placement.form` 决定，功能仍看 `level`；新占地完整包住旧占地，优先保持底边和正面不动，向上和两侧长大。空间不足时升级失败、不扣材料，面板与地图标出被挡住的格子。旧存档里已升级但仍是原占地的设施，可免费展开新形态。
- 旋转后的逻辑占地来自 `bounds`；绘本素材在该占地内等比例适配，朝向通过镜像变化。禁止用不同横纵缩放比例拉伸素材。
- 物件落地使用柔和椭圆投影。菌盖、灯罩与小屋边角可使用曲线；石砌、窗框等细节保持清楚。
- 背景植被、苔石与菌丛仅作环境点缀，玩家建造、种植或铺路后让出地块及必要的视觉间距，不额外占格。
- 地面采用连续手绘底图加程序化细节层（见下节），道路采用统一地图坐标的手绘纹理。建造和铺路时才显示格线。

- 未开垦地块画成洞穴积雾：整块叠一层低不透明度的冷雾，建造时加深，让可建范围一眼可见。可开垦地块中央留一片岩面空地，立开垦路牌。
- 产出气泡浮在屋顶上方：底色取 `--surface-solid`、紫荧菌细边、内嵌绘本物品图标和数量；夜间保持原亮度。

## 地形两层结构

**第一层：手绘底层。** `ground-{spring,summer,autumn,winter}.webp` 四张 1536×1024、对边无缝，对应四季四种地下景象；`paths.webp` 六种路面（湿石板、碎晶、菌丝铺道、暗色卵石、苔痕砖、地脉纹）。手绘负责「这是什么形状」。

**第二层：程序化细节层。** `terrain-{moss,crystal,spore,frost,water}.webp` 五张 1024×1024 可无缝平铺纹理，由 `scripts/terrain-gen.py` 以固定种子（默认 `20261101`）在制作期生成、结果入库；运行时不跑 Canvas。程序化负责「表面有多糙」。

细节层以 `256` CSS px 为循环尺寸铺在地图上，可视范围内约 5.3 格一循环，避免可识别的重复图案。**不透明度上限 0.35**：春/夏/秋 `.32`，冬季霜面 `.28`。只做「加糙」，不重画形状——两层打架时以手绘底层为准。

水面细节层带一条 40 秒线性漂移动画，仅在未开启减少动画时运行；`.home-world.reduced-motion` 与 `prefers-reduced-motion` 两条规则会把它和其它地图内动画一起关停。

四季景象：潮生（湿苔岩面）、晶盛（晶簇岩面）、孢散（锈褐菌毯）、霜凝（霜蓝冰面）。`season()` / `dayPhase()` / `night()` / `springThaw()` 的公式与阈值一字未改，只换视觉。夜间把底色与画面压到 `--lw-rock-dark`，只压亮度不改色相。

## 素材与验证

生产 PNG、提示词、`layouts.json` 与生成记录位于 `docs/art-2026-11-01/`。`scripts/prepare-home-art.mjs` 输出 `src/assets/storybook/` 下的 WebP 和 `manifest.json`；新批次用 `--source <目录>` 指定生成目录。每个物件实际裁切成独立透明图片，避免图集空白扩大点选范围。

`art/kit.ts` 的共享色板 `PAL` 已收敛到菌洞色系；`art/storybook.ts` 负责设施、装饰、植物、图标和道路的映射，`home-art.ts` 组合 SVG 场景。SVG 中的 `image` 引用内嵌素材生成的本地 Blob 地址，重复物件共享资源；原角色通过受控 `foreignObject` 复用 HTML 造型。旧矢量绘制保留为缺少绘本映射时的回退。

`scripts/build.mjs` 将图片、样式与脚本一起写入 `史莱姆.html`。玩家只需要这一个 HTML 文件，断网可玩。

验证入口：`npm test`（含 `tests/palette.test.mjs` 的 token / 别名 / 死主题 / 冻结样式表检查，`tests/terrain.test.mjs` 的固定种子可复现与 1024² 尺寸检查）、`npm run test:browser`（九个套件，含 `tests/terrain-detail-browser.cjs` 的细节层存在性、不透明度上限、跟随季节、循环次数、帧率与减少动画）、`npm run smoke`。检查 320×568、390×844、844×390、1440×900、1920×1080 五种视口，覆盖白天夜间、目录截图、旋转比例、鼠标与触屏交互、离线图片和存档恢复。帧率报告附实际渲染器、采样时间与窗口尺寸；浏览器触屏模拟的帧率仅代表本机桌面环境。

完整素材范围与再制作方法见 [冷光菌洞美术说明](../art-2026-11-01/README.md)，当前结果见 [实际验收](../living-world/QA.md)。
