# 单地图家园美术规范

家园采用柔和、圆润的乡间插画。地面保持正交俯视，物件立面朝屏幕下方，屋顶、投影和前后遮挡提供体积感。原史莱姆形体、表情与元素样式保持基线。

## 坐标与层次

- 一格48×48像素。kit.pt(u,v,h)返回[48*u, 48*v-10-h]，高度向屏幕上方延伸。
- home-art.ts按落地点的y坐标排序建筑、植物、伙伴与背景植被。伙伴每秒更新位置与层次。
- 建筑以未旋转占地绘制；奇数旋转交换宽高并镜像，显示占地必须与规则一致。
- 物件落地使用柔和椭圆投影。树冠、花盆、灯罩与小屋边角可使用曲线；屋瓦、窗框等细节保持清楚。
- 背景树木与灌木仅作环境点缀，玩家建造或种植后让出位置，不额外占格。

## 色彩与界面

草地以低饱和黄绿为主，地形颜色轻微过渡，避免棋盘条纹。建筑使用木色、陶土、米白与灰绿。夜间整体压暗，窗、灯和发光花保留暖光。

家园面板使用不透明米白底与深色文字；深色主题使用墨绿色面板。所有家园样式限制在.home-mode / .home-world，不影响旧页面。地图始终铺满可见窗口，不显示菱形外框或上下黑边。

## 素材与验证

art/kit.ts共享坐标和颜色，facilities.ts、decor.ts、plants.ts、creatures.ts提供素材；home-art.ts组合场景及小屋。SVG不依赖网络资源。渐变只由场景定义，目录预览使用纯色替代；原角色通过受控foreignObject复用HTML造型。

运行npm run typecheck、npm run build和npm run test:browser，查看五种视口、白天夜间及目录截图。帧率报告必须附实际渲染器；截图通过不代表所有真实手机都达到桌面帧率。
