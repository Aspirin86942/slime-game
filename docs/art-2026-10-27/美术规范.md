# 素材包美术规范（双月浮岛）

所有素材包共用这份规范。目标：每个物件一眼能认出是什么，同一世界观，白天夜晚都好看，手机竖屏（390 宽，地图缩放约 0.6）下仍可辨认。

## 风格

- **画法**：扁平色块 + 少量高光描边，无黑色外轮廓。高光用 `#fff3dc`，透明度 .45–.7，宽 1.5–2。
- **光照**：统一用 `kit.faces(c)`。顶面最亮，左前面（朝 +v）次亮，右前面（朝 +u）最暗。
- **色彩**：柔和、偏粉彩，饱和度中低。优先使用 `kit.PAL`；区域主色见 `ZONES[].color`，屋顶色见 `PAL.roofs[zone]`。
- **辨识度**：每个物件至少有一个独有的轮廓特征（形状、构件、道具），不能只靠换色区分。同组物件也要形状不同。
- **细节密度**：主体 3–5 个大色块，再加 2–6 个小细节（窗、门、花、石子、工具）。单个素材 ≤ 45 个 SVG 元素，字符串 ≤ 3.5 KB。
- **夜晚**（`lit=true`）：物件颜色经过 `kit.dusk()` 压暗；灯、窗、星光、萤光不压暗，并可加柔光（`url(#lw-window)` 或半透明暖色圆）。

## 坐标

- 使用 `kit.pt(u,v,h)`：u 沿地图 x（屏幕右下），v 沿地图 y（屏幕左下），h 为高度（向上为正）。一格是 46×30 像素的菱形。
- 原点 = 锚点格子顶角下移 10 像素。占地 `[a,b]` 的地面菱形：`pt(0,0)`、`pt(a,0)`、`pt(a,b)`、`pt(0,b)`。
- 物件画在自己的占地上，可以略超出，左右超出不超过 6 像素。高度上限：1×1 为 h≤70，较大占地为 h≤90。
- 用 `kit.box()` 画立体块，`kit.gable()` 画坡屋顶，`kit.shadow(a,b)` 画落地阴影。

## SVG 限制

- 只输出 SVG 片段字符串（`<path>`、`<ellipse>`、`<circle>`、`<g>`、`<rect>`），不写 `<svg>` 外壳。区域插画除外。
- 不定义 `id`、不写 `<defs>`（同页会出现多次，id 会重复）。可以引用地图已有的渐变：`url(#lw-water)`、`url(#lw-window)`。目录预览会把它们替换成纯色。
- 不用 `filter`、`mask`、`foreignObject`、文字和外部资源。
- 坐标保留一位小数。

## 验收

- 每个包都有一张联系表截图：白天和夜晚，每个物件放在对应占地的地块上，1 倍和 2 倍缩放。
- `npx tsc --noEmit` 通过。
- 只新增自己的文件，不修改已有文件，不运行 `npm run build`。
