# 家园美术规范 · 林间绘本

家园使用温暖的林间绘本风格。奶油纸色界面、苔绿色草地、陶土屋顶和原木设施形成统一配色，手绘纹理保留清楚的轮廓。地面保持正交俯视，物件立面朝下，图像按落地点锚定。原史莱姆形体、表情与元素样式保持基线。

## 坐标与层次

- 地图为36×24格，一格48×48像素，物件高度向屏幕上方延伸。
- home-art.ts按落地点的y坐标排序建筑、植物、伙伴与背景植被。伙伴每秒更新位置与层次。
- 旋转后的逻辑占地来自bounds；绘本素材在该占地内等比例适配，朝向通过镜像变化。禁止用不同横纵缩放比例拉伸素材。
- 物件落地使用柔和椭圆投影。树冠、花盆、灯罩与小屋边角可使用曲线；屋瓦、窗框等细节保持清楚。
- 背景树木、花丛和苔石仅作环境点缀，玩家建造、种植或铺路后让出地块及必要的视觉间距，不额外占格。
- 地面采用连续水彩底图，道路采用统一地图坐标的手绘纹理。建造和铺路时才显示格线。

## 色彩与界面

草地以低饱和黄绿为主，地形颜色轻微过渡，避免棋盘条纹。建筑使用木色、陶土、米白与灰绿。夜间整体压暗，窗、灯和发光花保留暖光。

家园面板使用不透明奶油纸色与墨绿文字；深色主题使用墨绿色面板。桌面使用右侧目录，手机使用底部目录。主工具为建造、种植、采集、更多，制作、仓库、生态位于更多中。打开面板时隐藏主工具栏，底部六个页面入口保留。所有家园样式限制在.home-mode / .home-world，地图铺满窗口。目录缩略图使用独立展示框，保持原比例和足够的显示尺寸。

## 素材与验证

生产PNG和裁切坐标位于docs/art-2026-10-29/production/。scripts/prepare-home-art.mjs输出src/assets/storybook/下的WebP和manifest.json。每个物件实际裁切成独立透明图片，避免图集空白扩大点选范围。

art/storybook.ts负责设施、装饰、植物、图标和道路的映射；home-art.ts组合SVG场景。SVG中的image引用内嵌素材生成的本地Blob地址，重复物件共享资源；原角色通过受控foreignObject复用HTML造型。旧矢量绘制保留为缺少绘本映射时的回退。

scripts/build.mjs将图片、样式与脚本一起写入史莱姆.html。玩家只需要这一个HTML文件。基础植物与发光花拥有独立成熟素材，杂交植物保留亲本形态及基因变化，生长阶段依进度切换。

运行npm test和npm run test:browser，检查五种窗口尺寸、白天夜间、目录截图、旋转比例、鼠标与触屏交互、离线图片和存档恢复。帧率报告附实际渲染器、采样时间与窗口尺寸。浏览器触屏模拟的帧率仅代表本机桌面环境。

完整素材范围和再制作方法见 [林间绘本美术说明](../art-2026-10-29/README.md)，当前结果见 [实际验收](../living-world/QA.md)。
