# 史莱姆牧场：游戏性与数值设计

游戏形成「召唤 → 派遣与离线成长 → 养成和组队 → 深渊首领 → 新区域与每日扫荡」的循环。产品入口为根目录的 `史莱姆.html`；直接打开即可游玩。

## 可玩的内容

- 首只伙伴免费；随后收费，连续 9 次未召到稀有元素时，第 10 次必得光、暗、空间或时间。费用与保底进度在召唤页展示。
- 自动战斗会释放主动技能；物理、魔法、速度与组队羁绊均影响战斗。治疗者会根据队伍血量选择治疗或攻击。
- 每 5 层为首领战，有额外首通宝物。通关层每天可扫荡 3 次，重复挑战获得较少奖励。
- 通关第 10/25 层开放黄昏/雪原；离线最多结算 12 小时，回来显示晶币、经验、宝物和升级伙伴。
- 增加深渊胜利、抚摸、培养每日任务；商店可购买按等级提供经验的药水。

## 战斗公式

记 `L` 为伙伴等级，`F` 为深渊层数，`P` 为潜力。取整采用 JavaScript 的 `Math.round`。

| 项目 | 当前规则 |
|---|---|
| 成长 | `growthStat(P,L) = P + (L−1) × round(P×0.5)`；旧档升级仍按增量增加属性 |
| 生命 | `(100×体型 + 3×力量 + 10×L) × 性格加成 × 词条加成` |
| 物攻 / 魔攻 | `(2×力量或魔力 + 3×L) × 对应性格加成 × 词条加成` |
| 速度 | `(100 + 敏捷) × 性格加成 × 词条加成` |
| 防御 / 抗性 | `round(力量或魔力×0.6 + 3×L)` |
| 防御减伤 | `K / (K + 对应防御)`，`K = 40 + 8×攻击者等级`；暴击和克制之后、护盾之前应用 |
| 行动顺序 | 保留我方阶段、敌方阶段，各自按速度降序；预告目标保持锁定 |
| 追击 | 速度 ≥ 目标×1.3；追加 0.5×伤害，不递归追击，不触发烧伤、吸血、溅射或迷你水史莱姆 |
| 自动技能 | 技能冷却结束就释放；水/光主动治疗在队友低于 70% 生命或光系需要净化时释放 |
| 普通治疗 | 有队友低于 70% 生命时治疗，回复 `round(魔攻×0.45 + 2×L)`；其他回合攻击 |
| 羁绊 | 同元素 2 只：该元素攻击 +10%；3 只以上：+20%；至少 4 种元素：全队当前/最大生命 +10% |

教学战保留独立的固定数值。第 45 回合起每 10 回合攻击提高 20%，作为长战兜底。首领与羁绊的额外生命不放大元素天赋在开战时按基础生命生成的护盾。

## 深渊、奖励与成长

| 项目 | 当前规则 |
|---|---|
| 敌人 | 等级等于层数；三项潜力各自随机 8～16，使用共同成长公式 |
| 编制 | 1～9 层 2 只；10～19 层 3 只；20～34 层 4 只；35～50 层 5 只 |
| 首领 | 每 5 层第一只敌人为首领，生命×3、攻击×1.5，保留护卫 |
| 敌人经验 | `40 + 30×F`，首领×2.5 |
| 胜利 | 首通全额经验；晶币为总经验×2.5；经验由结算瞬间仍存活的伙伴平分，再受悟性加成 |
| 失败 | 只计算已击败敌人的 25% 经验；无人存活时由参战伙伴平分；零击败零奖励 |
| 重复挑战 | 晶币和经验再×0.2；首领额外宝物不重复发放 |
| 首领首通 | 天材地宝×1、捕捉网×1、积分+5；整十层额外词条券×1 |
| 扫荡 | 最高已通关层，每日 3 次；按 3 只普通敌人的首通经验结算；不给首通宝物，也不解锁下一层 |
| 每级经验 | `100 + 80×L` |

养成的验收队伍随阶段为 2/3/4/5 只，符合开局只有两席、后期扩编的实际玩法。普通层允许更顺畅地推进；首领承担主要养成门槛。保留属性和克制带来的越层空间。

## 经济与离线

| 项目 | 当前规则 |
|---|---|
| 召唤 | 伙伴为空时免费；否则 `500 + 100×召唤师等级` 晶币；有召唤动画时阻止重复扣费 |
| 保底 | 第 10 次连续非稀有抽取转为稀有；自然抽中稀有立即清零 |
| 合体 | 保留原规则：`500 + 100×较高伙伴等级 + 250×主宠合体次数×(次数+1)` |
| 商店 | 饲料 150、天材地宝 3000、捕捉网 1000、经验药水 2500 晶币；词条券 50 积分 |
| 经验药水 | 本级所需经验×50%，再受悟性加成；购买后用于等级最低伙伴 |
| 行动周期 | 每 12 秒检查派遣；消耗 20 体力；不足时休息，每秒恢复体力/心情，满足阈值自动续行 |
| 单次派遣晶币 | `(15 + 2.5×L) × 区域倍率 × (1+全能词条+探险词条) × (1+min(0.5,天赋/300))`，再结算幸运与随机事件 |
| 单次派遣经验 | `round((6+0.8×L)×区域经验倍率)`，再受悟性加成 |
| 草原 | 默认开放；晶币/经验/宝物概率倍率为 1/1/1 |
| 黄昏 | 通关第 10 层；倍率 1.6/1.25/1.5 |
| 雪原 | 通关第 25 层；倍率 2.5/1.5/2 |
| 离线 | 离开至少 60 秒时补算，效率等同在线，最多 12 小时；时钟回拨按 0；诊断模式不结算 |

每次派遣天材地宝基础概率为 2%，再乘区域宝物倍率。探索动画保留拾取表现，奖励统一由派遣函数发放。各区域的视觉与实际收益使用同一解锁结果。

在线、后台与离线共用 `advanceWorld`。`planClock` 保存 12 秒行动周期的余数；离线计算期间禁止中途写存档，完整结算后才保存。关闭/隐藏页面会保存，旧档没有时间戳时不追溯发奖。
