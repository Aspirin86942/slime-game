# 家园系统的美术方向提案（2026-10-29）

结论先说：**推荐 C「纸艺立体书」**。它以最低的改动量换来最强的辨识度，天然满足现有美术规范里"零渐变、无外部资源、单一光源"的约束，也不和冻结的史莱姆形体冲突。若更在意"老玩家不觉得换了游戏"，选 A；若这一版的目标是宣传截图差异化，选 B；D 只在愿意重画全部素材并接受角色与地图材质割裂时考虑。

本目录只含设计预览，**没有改动 `src/` 下任何一行代码**，`史莱姆.html` 未重新构建。

## 1 现在的问题（体检结论）

现状不是画风不好，而是密度与材质不一致：

| 现象 | 证据 |
| --- | --- |
| 地面读起来是"一格一格铺的" | 每格一条 48.5px 矩形、`fill-opacity .28`，36×24=864 条，环境层再叠 864 条（`src/world/home-art.ts:36-41`） |
| 路面像贴上去的胶带 | 路面是平铺矩形拼出来的长条，接缝可见（`home-art.ts:46-48`） |
| 建筑与草地不在同一套光里 | 建筑用三面明暗（`src/world/art/kit.ts:17`），地面是纯色块，阴影只有一层 17% 椭圆（`kit.ts:37`） |
| 夜间只是整体调暗 | 全场 `mix(c,'#243d53',.48)`（`home-art.ts:30`），没有光源、没有发光层 |
| UI 是通用米白卡片 | `src/world/home.css:2-3` 的六个变量撑起整套面板 |

换风格时真正要改的是这五处，而不是"换个色板"。

## 2 四套方向

四套样张画在**同一张 24×15 视口地图、同一批素材、同一机位**上（`gen.mjs` 内共享 `LAYOUT`），可以直接横向比较。

### A 晨雾绘本（水彩田园 · Gouache storybook）

- **一句话**：把地面画成一片，而不是铺出来的一格一格；颜色像奶油颜料，边缘留一笔手抖，光很软。
- **地图**：整片色块 + 模糊色斑（禁止逐格棋盘）；连续多边形路面，路缘被草"啃"过；椭圆 16% 深绿阴影。
- **素材**：每件 3 个色阶（亮/中/暗），不描边；`blob()` 半径 ±10% 正弦起伏做手抖轮廓；共享 9 色。
- **夜空**：整层冷纱 + 暖窗光。
- 改动量中 / 风险低 / 差异度中。最贴现在的气质，代价是整套素材按新色阶重画一遍。

### B 萤火夜庭（微光生态 · Bioluminescent garden）

- **一句话**：把"白天经营、夜里收光"做成主循环的画面证据——夜里全压成剪影，只留轮廓光和发光作物。
- **地图**：夜色为默认，地面大面积深色，留 1/3 面积给发光物；路面加冷色高光边与发光碎石作行走引导；边缘 55% 径向压暗。
- **素材**：主体一律暗剪影 `#0a1526`，1–2px 轮廓光只在左上受光边；每个光源两圈（实心核心 + 模糊光晕，复用同一 filter）；发光物不超过场景面积 15%。
- **白天**：用一层雾光覆盖层切换，不重画素材。
- 改动量中高 / 风险中 / 差异度高。截图最抓眼，但要额外维护一套白天配色。

### C 纸艺立体书（分层卡纸 · Paper diorama）★ 推荐

- **一句话**：整个世界是一本立体书，每样东西都是剪下来的色卡纸，靠一道硬投影表现厚度，没有一处渐变。
- **地图**：地形 = 几张剪好的纸，每层 3–6px 硬投影错位；路面 = 一条连续纸条 + 几片纸屑，不做格子缝；草地用小三角纸片点缀，间距 40px 以上。
- **素材**：每件 2–4 层纸，层与层之间必须有投影；不描边，边界靠相邻纸面明度差 ≥ 12%；折角用 2px 奶油高光；限 10 色。
- **底子最好**：现有 `kit.ts` 的 `faces()` 已经是单光源三面，扁平多边形几乎可以直接复用，主要是去掉渐变、统一光向、限色、换硬投影。
- 改动量低 / 风险低 / 差异度高。画面偏"平"是唯一代价，要靠层次与色块面积取胜。

### D 像素农耕（16-bit · Pixel farm，高风险备选）

- **一句话**：把逻辑分辨率砍半，每格只留 24×24 像素，2 倍整数放大，做出 16 位机的颗粒感。
- **地图**：每格 24×24 逻辑像素、整数倍放大；地形用 2–3 个整数像素色块，边缘阶梯化；路面只用 3 色；所有斜线走阶梯。
- **素材**：16 色板；所有元素重画为像素网格；2px 抖动。
- **硬冲突**：史莱姆是 HTML/CSS 渲染且被逐字节冻结（`tests/review-tests.cjs:37-47`），`.home-slime` 固定 68×74px 且不随镜头缩放；同时仓库没有位图管线，也无法引入像素字体。只能做"地图像素、角色原样"，两者的"像素"对不齐。
- 改动量高 / 风险高 / 差异度高。只在愿意重新协商角色形体基线时考虑。

## 4 落地分期（选定方向后）

### P0 · 只改 token，不动结构（0.5–1 天）

- `src/world/art/kit.ts:43-52` 的 `PAL` 收敛成目标风格的 8–16 色；
- `src/world/home-art.ts:27` 草地色板、`:30` 夜间 `shade()`；
- `src/world/home.css:2-3` 的六七个主题变量。
- **任何风格都能先做的一步**：把 `home-art.ts:38` 的逐格矩形 `opacity` 从 `.28` 降到 `0~.08`，棋盘感立刻消失，这是单点收益最大的一改。

### P1 · 重画素材（按风格 2–5 天）

- A：`facilities.ts` / `decor.ts` / `plants.ts` 共约 76 件，统一三色阶、去描边、手抖轮廓；
- B：约 60 处发光件从实体层拆出独立 `<g class="bglow">`，与实体分层；
- C：同 76 件改硬边、单光、限色，`facilities.ts:346-347` 引用的两个渐变换成纯色（目录预览 `preview()` 已经在做等价降级，`home-art.ts:23-25`）；
- D：全部重画，不推荐。

### P2 · 地图构图与面板皮肤（2–3 天）

- A：`home-art.ts:33-49` 的 864 条地面矩形换成大块 biome 路径 + 割草斑块；
- B：夜间成为主场景（注意 `tests/home-browser.cjs:55` 断言了 `.home-tools` 背景 `#283c33`、`.home-season` `#fff3d4`、tabbar 按钮 `#b6c7b0` 三个精确色，改地图色可以，改面板色要同步改断言）；
- C：面板改"卡纸 + 硬投影"分层（`home.css` 大改），按钮改纸片按压。

## 5 验收

改完必须过这些闸门，否则风格再好看也不算落地：

- `npm test`：类型检查、构建、72 项世界/迁移规则、48 项旧玩法回归、基线 hash、merge-growth；
- `npm run test:browser`：真实 Chromium，五种视口（320×568 / 390×844 / 844×390 / 1440×900 / 1920×1080）+ 昼夜截图，产物在 `tools/out/home-v5/`；
- 会挂的断言：`.home-map` 唯一、`.home-environment` 必须 864 条、五视口满屏、夜间三个精确色、1440×900 dpr1 下 55fps / 300 株 30fps、浏览器异常必须为 0；
- 视觉验收看三件事：棋盘感是否消失、路面接缝是否消失、建筑与地面是否同一套光。
