家园的四种画法

现在的家园是柔和乡间插画：低饱和黄绿草地、米白面板、48px 一格的正交地图。问题不在画风，而在密度和材质——地面读起来像一格一格铺的，路面像贴上去的胶带，建筑和草地不在同一套光里。下面四套方向都画在同一张地图、同一批素材、同一机位上，可以直接横向比较。

风格
光线
A

晨雾绘本水彩田园 · Gouache storybook

把地面画成一片，而不是铺出来的一格一格；颜色像奶油颜料，边缘留一笔手抖，光很软。

  • 改动量中
  • 风险低
  • 差异度中

色板

草地#9cba6f草地深#7b9a58屋顶#d07a58墙#f6e7c3木#b98f65水#96c8cd土#b98f66天光#fff4d2夜纱#2b3a55

素材架

地图规则

  • 草地：整片色块 + 16px 高斯模糊的色斑，禁止逐格棋盘
  • 路面：连续多边形，路缘 2px 深色描边，碎石点随机 26 颗
  • 建筑：只画受光面（左前）与暗面（右前），不描黑边
  • 阴影：椭圆 16% 深绿，向右下偏移 3px
  • 装饰密度：每 3 格最多一丛草叶，留出大片呼吸区

素材规则

  • 轮廓：每件素材用 3 个色阶（亮/中/暗），不加描边
  • 抖动：blob() 半径 ±10% 正弦起伏，同一素材参数固定
  • 共享色板 9 色，只能从色板取色
  • 颗粒：整场景一层 feTurbulence，不逐件叠加

界面皮肤

  • 面板：米白纸底 #f8f2e0，1px 茶墨边
  • 按钮：无阴影，按下位移 1px
  • 强调色：陶土橙 #e08a4a，只用于当前选中

动效

  • 草叶 4s 微摆（transform 幅度 1px）
  • 夜里窗光呼吸 6s
  • 点击物件：影子先收缩再回弹 120ms

取舍

+ 最贴近现在的气质，老玩家不觉得换了个游戏+ 柔和色温 + 纸纹让 320px 手机上依然干净+ 史莱姆本体原样放进来毫无违和

− 手绘感要靠大量微抖动与散布细节，逐件手工调色− 细节变多后，小屋、围栏的辨识度要靠轮廓控制

B

萤火夜庭微光生态 · Bioluminescent garden

把「白天经营、夜里收光」做成主循环的画面证据：夜里全压成剪影，只留轮廓光和发光作物。

  • 改动量中高
  • 风险中
  • 差异度高

色板

夜底#152639苔绿#22463c剪影#0a1526轮廓光#5fa892萤光#9df0cf琥珀#ffc271水光#7fd4ff晨雾#ffe4b0雾绿#cfe0cf

素材架

地图规则

  • 夜色为默认：地面大面积深色，留 1/3 面积给发光物
  • 地面纹理只保留极暗的短线段，靠亮块分层次
  • 路面加冷色高光边和发光碎石，作为夜里的行走引导
  • 边缘加 55% 径向压暗，形成「被灯照到的一圈」
  • 白天用雾光覆盖层切换，不重画素材

素材规则

  • 主体一律暗剪影，1–2px 轮廓光只在左上受光边
  • 每个光源两圈：实心核心 + 模糊光晕（同一 filter 复用）
  • 发光物不超过场景面积的 15%，否则失去夜晚感
  • 阴影比暗面更深，避免剪影糊成一团

界面皮肤

  • 面板：深底半透明 #101d2b / 85%，1px 冷边
  • 文字：骨白 #e7e2cf，次要信息 #7f9a9c
  • 强调色：萤光薄荷 #9df0cf；危险/消耗用琥珀

动效

  • 萤火虫 7–11s 不规律漂移
  • 发光作物随生长进度增亮
  • 灯与窗呼吸 6s，幅度只到 8%

取舍

+ 差异化最强，截图一眼能认出来+ 发光作物、窗户、萤火虫给夜晚经营一个可看的理由+ 剪影画法元素少、帧率友好

− 白天需要另一套配色（雾光），等于设计两个场景− 320px 小屏上暗色细节容易糊，必须靠亮块分层− 现有素材几乎全部要重画为剪影

C

纸艺立体书分层卡纸 · Paper diorama

整个世界是一本立体书：每样东西都是剪下来的色卡纸，靠一道硬投影表现厚度，没有一处渐变。

  • 改动量低
  • 风险低
  • 差异度高

色板

底色纸#d8e0b2浅纸#c6d5a0深纸#a9c082鼠尾草#86a06c奶油#fbf3e2陶土#cf7458陶土深#b25e46青苔蓝#6a9aa2芥黄#e3b464梅紫#8f7ba0

素材架

地图规则

  • 地形 = 几张剪好的纸，每层 5–6px 硬投影错位
  • 路面 = 一条连续纸条 + 几片纸屑，不做格子缝
  • 所有物件统一光从左上，投影方向右下，角度固定
  • 草地用小三角纸片点缀，间距 40px 以上，不铺满
  • 限 10 色，任何新素材只能从色板取色

素材规则

  • 每个物件 = 2–4 层纸，层与层之间必须有投影
  • 不用描边，边界靠"相邻纸面明度差 ≥ 12%"
  • 折角/折线用 2px 奶油色高光表达
  • 零渐变、零模糊；阴影 0 blur 硬投影

界面皮肤

  • 面板：奶油卡纸 + 4px 硬投影，无圆角或只留 4px 圆角
  • 按钮：纸片按压 2px 位移，边框即剪口
  • 强调色：陶土 #cf7458；选中卡纸略微抬起

动效

  • 点选物件：纸片抬起 3px 再落下，投影同步变长
  • 面板开合：像翻一页纸（rotateX 8°）
  • 不抖、不呼吸，保持工艺品的静止感

取舍

+ 零渐变零纹理，现有扁平多边形几乎可以直接复用+ 统一光源 + 硬投影，遮挡与立体感自然立住+ 限色板让 UI 与地图同一套语言，最省工

− 画面容易显"平"，需要靠层次与色块面积取胜− 柔和、温暖的乡野气会被换成工艺感，不是所有人喜欢

D

像素农耕16-bit · Pixel farm（高风险备选）

把逻辑分辨率砍一半，每格只留 24×24 像素，2 倍整数放大，做出 16 位机的颗粒感。

  • 改动量高
  • 风险高
  • 差异度很高

色板

墨#0b1622深水#152b3a石板#1f4450苔青#2e6470草深#4a8b7e草#78b08a草亮#a8cf8a草黄#d9e8a6奶油#f2f0c8金#e8b45c橙#d98a46砖#b85c3c砖深#8a3a34梅#5a2b3a灰#8f8fa8白#e6e6e6

素材架

地图规则

  • 每格 24×24 逻辑像素，整数 2× 放大，禁止非整数缩放
  • 地形用 2–3 个整数像素色块，边缘阶梯化，不用渐变
  • 路面只用 3 色：金 / 橙描边 / 橙点
  • 所有斜线走阶梯，禁止抗锯齿斜边
  • 装饰按 2×2 像素点阵分布，密度靠抖动控制

素材规则

  • 16 色调色板，一件素材最多 5 色
  • 轮廓不描黑线，靠明度差与 1px 高光
  • 所有尺寸为偶数，保证像素对齐
  • 阴影用 2px 深色块，不用模糊

界面皮肤

  • 面板：2px 像素边框 + 4px 硬阴影，字体用等宽或像素字体
  • 按钮：按下整体下移 2px，取消圆角
  • 强调色：金 #e8b45c，禁止半透明叠加

动效

  • 动画按 4/8 帧阶梯切换，不做补间
  • 切换场景用像素溶解，不用淡入淡出
  • 数字与进度条按整数跳变

取舍

+ 最有"游戏"味，缩放后依然锐利，320px 小屏可读性最好+ 像素风对元素数量要求低，剪影和色块就能讲清内容+ 资源体积极小，纯整数坐标，不会有抗锯齿模糊

− 史莱姆本体是 HTML/CSS 平滑渲染，和像素世界同框会明显冲突，需要重协商"基线不可改"这条约束− 26 种设施 + 全部装饰、植物、访客要逐件重画− 建筑立面、遮挡、旋转镜像规则全部要按像素网格重新验证

我的建议

想最快看到整体提升，选 C（纸艺立体书）。现在的实现本来就是扁平多边形加明暗三面，纸艺风只是把它推到极致：去掉所有渐变，改成限色板 + 固定方向硬投影。改动集中在 kit.ts 的色板与抽影、home.css 的变量，素材轮廓基本不用动，是最省工的高感知方案。

想让截图一眼不同，选 B（萤火夜庭）。它把已经存在的昼夜切换变成卖点，但要额外设计一套白天配色，工作量最大。

最稳的是 A（晨雾绘本）。气质最贴现在的产品，玩家不会有"换了个游戏"的割裂感，代价是整套素材要按新色阶重画一遍。

D（像素农耕）只在愿意重新协商"史莱姆形体基线"时考虑。它是唯一和现有 HTML/CSS 角色渲染冲突的方向。
