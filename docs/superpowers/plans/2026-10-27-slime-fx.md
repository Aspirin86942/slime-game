# 史莱姆：打击感 + 属性形态 + 战斗 2.0 实现计划

> **面向 AI 代理的工作者：** 必需子技能：使用 subagent-driven-development（推荐）或 executing-plans 逐任务实现此计划。步骤使用复选框（`- [ ]`）语法来跟踪进度。

**目标：** 在 `史莱姆.html` 单文件内补齐战斗打击感、12 属性形态差异、玩家可操作的战斗技能。

**架构：** 先建一个只做 DOM 演出的 `FX` 门面（闪白/震屏/飘字/爆散/日志），把现有 `dealDamage → refreshBars → log()` 的离散接入点改成一次调用；再给史莱姆加 `data-el` 与空 `.mark` 容器，装饰全部由 CSS 伪元素绘制；最后在 `startAbyssBattle` 之上加技能表、技能条与三态调度（auto/interject/step），主动技效果全部复用现有元素天赋机制。

**技术栈：** 单文件 HTML + 原生 JS + CSS animation；无构建、无依赖、无图片/音频/Canvas。验收用 Chrome headless（`--dump-dom` / `--screenshot`）驱动文件内自检。

**规格：** `docs/superpowers/specs/2026-10-27-slime-fx-design.md`（本计划实现该规格；执行者两份都读）

## 审查重点（Review Focus）

1. **高速档同帧多目标受击**（`battleSpeed=10`，10 个单位、溅射/连击同时命中）：飘字合并与上限必须生效，伤害数值一个都不能少、页面不得卡死。→ 由任务 2 的 `A-merge` 检查与任务 11 的 10x 连战覆盖。
2. **战斗中途刷新 / 旧存档加载**：`slimeSummonerSave` 无 `battleMode` 时必须回落到 `'auto'`，五个 tab 都能渲染，不得因缺字段抛错炸掉整页。→ 任务 7 的 `C-save` 检查。
3. **手动选目标打空**：全队只剩 1 只、目标全灭、目标处于「虚化」不可选中时点技能/点目标，必须给提示且不消耗行动、不抛错。→ 任务 9 的 `C-target` 检查。
4. **「时间·回溯」复活与「空间·虚化」的联动**：复活后单位要重新进入技能条且不可重复复活；虚化期间不能被技能选中、也不能被 AI 选中做治疗目标。→ 任务 8 的 `C-revive` 检查。
5. **装饰叠加遮挡**：元素装饰 + 护盾罩 + 冻结覆盖 + 8 种表情同时存在时，不得盖住眼睛与血条，四种缩放尺度下不得溢出容器。→ 任务 6 的 `B-matrix` 检查与画廊截图人工复核。

- [ ] **步骤 2：实现 FX（约 130 行）**

对外签名固定为下列五个方法，另加内部工具：

```js
const FX = {
  field: null, log: [], _txt: 0, _part: 0,
  bindField(el)                        // 记录容器；内部存 fieldEl 与其 rect 缓存
  shake(kind)                          // 'light'|'crit'|'kill'
  flash(el, isCrit)                    // el 为 .slime 元素
  float(el, text, opt)                 // opt={cls:'crit'|'good'|'weak'|'miss'|'', icon:'🔥'|'☠'|''}
  die(el)                              // 击杀演出 + FX.burst
  burst(el, color, count)              // 元素色爆散粒子
}
```

实现要点（签名之外必须一致的行为）：
- `shake` 按 `{light:3, crit:6, kill:5}` 取位移、按 `{light:120, crit:160, kill:140}` 取时长；同一帧多次调用只保留最强档（用 `FX._shakeRank` + `requestAnimationFrame` 合并）。
- `float` 从目标 `.slime` 顶部居中生成，上飘 24px、0.85s 淡出；`battleSpeed >= 5` 时时长 ×0.6；同目标 250ms 内同 `cls` 的数字合并累加（`FX._merge` 记录 `{el, cls, t}`）。
- `FX.log` 每条 `{t: performance.now(), type, kind, text, cls}`，上限 200 条，超出 `shift()`。
- 同屏飘字上限 12、粒子上限 60，超出删最早的 `.fx-float` / `.fx-part`。
- 时长统一乘 `1 / Math.max(1, Math.min(2, battleSpeed / 2))`，`battleSpeed` 未定义时按 1。

- [ ] **步骤 3：写 CSS（闪白 / 飘字 / 震屏 / 粒子 / 降级）**
