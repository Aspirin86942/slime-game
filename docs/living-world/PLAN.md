# 共同生活实施计划

交付目标是完整统一现有家园、陪伴、物品、故事与远行。发光花闭环用于确认连接真实有效，同时覆盖全部现有内容。

下列六项工作均已完成。规格先写入 SPEC，再形成计划，随后修改源码；迁移与失败保护先于场景和玩法接入。最终类型、规则、迁移、浏览器、数值和性能结果见 [QA.md](QA.md)。

| 顺序 | 实施结果 | 实现位置 | 完成标准与证据 |
|---|---|---|---|
| 1 | 确定 V4 规格、保留 V3 基线 | `SPEC.md`；合成 V3 夹具 | 基线 main `7c2bded`；保留原角色、成长、库存和历史的约束明确 |
| 2 | 统一库存、活动、时间和迁移 | `inventory.ts`、`life.ts`、`migration.ts`、`storage.ts`；旧存档适配 | V1–V3 原文备份、旧派遣一次结清、原远征继续、独立饲料/食材、配额失败和重复读档检查 |
| 3 | 同一生活/布置地图与真实设施行为 | `life.ts`、`art.ts`、`view.ts`、`ecology.ts` | 原造型、唯一位置、道路寻路、到达才进食/产生岗位效果；移动设施重新寻路；真实触屏拖动 |
| 4 | 绑定故事与统一远行 | `stories.ts`、`travel.ts`、`engine.ts`、`narratives.ts` | 发光花完整闭环、便当与同行条件、全部故事的行为门槛和结果；返程释放占用、领取一次、连续委托 |
| 5 | 保留旧功能，收敛入口 | `src/legacy/`、`shell.html`、`index.ts` | 三主入口；召唤、任务、合体、挑战、扫荡、魔物、幼体和小游戏可达；副宠历史归档 |
| 6 | 单文件构建与实际验收 | `scripts/`、`tests/`、`README.md`、`CONTENT.md`、`QA.md` | 源码构建 HTML；规则/集成/回归/浏览器/战斗模拟/性能报告；截图实看；以 QA 实测记录确认 |

## 需求与验收对应

| 需求 | 检查 |
|---|---|
| 种植 → 料理 → 原宠投喂 → 同行 → 发光花 → 回忆 | `common-life.test.mjs` 完整闭环；`world-browser.cjs` 实际召唤、命名、点击、断网与刷新 |
| ID、改名、切换对象、合体后历史正确 | `common-life.test.mjs` 制作归属、故事绑定；`common-life-integration.cjs` 副宠档案；`merge-growth.cjs` 主宠成长 |
| 元素与同行条件真实，失败不发成功奖励 | 两个世界规则套件遍历 72 事件；无风、单人树洞协助、失败挑战及原子回滚专项 |
| 唯一物品来源，重复领取和满仓不复制 | `world.test.mjs` 制作/远征/小游戏/溢出；`common-life.test.mjs` 容器和便当；集成测试迁移、重试与双库存拒绝 |
| 零资源仍能恢复经营 | 近家采集补饲料/种子与无食物门票旅行测试 |
| 工作、旅行、战斗、小游戏互斥 | 规则直接调用检查；原生战斗/合体/扫荡集成；浏览器小游戏释放 |
| 唯一位置、不可达暂停、设施移动后正确 | 居民分区、道路/建筑障碍、饲料到达、岗位生态/浇水/关系、聚餐座位测试；触屏布置 |
| 6 区域故事、48 世界章节、42 性格链、24 关系事件 | 世界规则逐条遍历绑定、阶段、选择和纪念物；内容目录从实际数据表生成 |
| 安全迁移、12 小时离线上限、存储失败与跨标签冲突 | V1/V2/V3 合成夹具、备份碰撞/失败、写入失败、老远征、满布局、坏档、未知版本、重载与保护测试；排队战斗动作/胜利和接球去程/回程/漏球均覆盖暂停与恢复 |
| 原造型、成长和战斗基线 | 68 项旧玩法、合体专项、真实浏览器战斗、界面/召唤演出和完整数值模拟 |
| 手机布局、主题、昼夜、减少动态、离线 | `world-browser.cjs`、`gameplay-browser.cjs`、`art-direction.cjs`、`common-life-touch.cjs`，独立临时浏览器配置、真实触摸事件和截图；浏览器内置自检另行运行 |
| 正常 ≥55 FPS、压力 ≥30 FPS | `world-performance.cjs` 家园；`tools/out/fps.js` 战斗；记录实际渲染环境 |

所有规则先校验再提交。校验失败不扣资源、不改活动、不推进随机序列；存储失败时保留已执行结果，重试只写入。迁移保留原文，验证成功并写入 V4 后再启动新时钟。

范围为本地代码、文档、构建和验收。Git 提交、推送、PR 和对外发布不在本轮执行范围内。真实玩家存档不用于测试。
