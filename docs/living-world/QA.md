# 单地图家园 V5 验收

2026-10-29 验收通过。交付为根目录 [史莱姆.html](../../史莱姆.html)，可直接双击并离线游玩。家园是一张铺满窗口的36×24格地图，其他系统采用 ae243d9 的界面、玩法和数值。

## 可玩的内容

- 全屏俯视地面，建筑立面、阴影和纵向遮挡表现立体感。支持拖动视野、滚轮/按钮缩放及双指缩放。
- 设施与装饰支持点选建造、旋转、拖动移动、收纳和取回；道路可以连续铺设，取消触摸不提交笔画。
- 保留种植、照料、收获、育种、品系命名与收藏、复制留种、制作、生态访客和史莱姆互动。首次收获可获得发光花种子，档案馆可制作星纹遗物。
- 陪伴、召唤、探索、背包、成长保留，默认进入陪伴。家园玩具区可进入原接球和叠叠乐。
- 原远行、独立故事、关系、共鸣育幼及三款新增小游戏停止运行；旧记录归档。远征站和共鸣石作为可移动、可收纳的纪念装饰保留，不能安排岗位。

当前内容为24种经营设施、42件装饰、6种路面、55种植物、17条配方和18种生态访客。实际目录由源码生成，见 [CONTENT.md](CONTENT.md)。
