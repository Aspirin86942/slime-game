交付文件为仓库根目录 [史莱姆.html](../../史莱姆.html)。共同生活基线为 `main / 7c2bded`。当前界面采用随机身份、自动故事与插画点选建造。规则见 [SPEC](SPEC.md)。

本次复验：`npm test`、`world-browser.cjs`、`art-direction.cjs`、`catalog-browser.cjs`。点选与故事专项 42/42，通过新身份保存、无分支阅读、触屏放置、收纳取回、材料不足、键盘、减少动态、7 套主题对比度、320/390/480/1280 布局和离线重载。报告位于 `tools/out/catalog-browser.json`，截图前缀为 `catalog-`。

## 可玩的结果

- 序章自动分配姓名和向导，三次继续进入家园。故事自动安排真实参与伙伴，情节无需玩家决策；刷新保留身份与结果。
- 建造栏使用分类插画按钮，点物件后点地图即可放置。设施与装饰共用地图插画，收纳物件可直接取回。
- 底部只有家园、远行、伙伴三个主入口。原召唤、任务、成长、合体、魔物、幼体、深渊、教学、扫荡和小游戏均保留入口。
- 六个家园分区共用生活与布置场景，使用原史莱姆造型。伙伴只有一个所在地点，按可达道路前往设施；到达后才进食或产生岗位效果。
- 同一只召唤伙伴可以完成种植、制作饲料与便当、投喂、森林同行、树洞经历、发光花开花和纪念记录。改名、切换查看对象及刷新后，参与者和结果仍保留。
- 基础饲料、食材、料理、种子、槽内物资和旅行物资分别记账，共用唯一库存。零金币、零食物、零种子时可以通过近家采集恢复。
- V1/V2/V3 自动迁移为 V4。先保留原始存档字节，再结清旧派遣并返家；现有家园远征、成长、布局和已领奖历史保留。

## 画面和性能

已实际查看发光花纪念、浅色主题、夜间/减少动态、1200 像素桌面、远行、320 像素家园、密集植物、战斗、接球和叠叠乐截图。家园在 320/390/480/1200 像素宽度无文档横向溢出；区域标签使用独立横向滚动。

以下性能数据来自此前共同生活基线，本次未重测帧率。性能采用每场景三轮的中位数判定，目标为正常 ≥55 FPS、压力 ≥30 FPS。

| 场景 | 中位数 | 采样条件 |
|---|---:|---|
| 家园，12 位伙伴 | 60 FPS | 390×844，DPR 1，三轮各 6 秒 |
| 密集家园，136 株成熟植物与 12 位伙伴 | 60 FPS | 同上，三轮各 3 秒 |
| 战斗，开启特效 | 58.9 FPS | 480×900，9 单位，10 倍速，三轮各 6 秒 |
| 战斗，关闭特效 | 60 FPS | 同上 |
| 战斗压力 | 40.8 FPS | 每帧额外飘字、闪白、爆散和震屏，三轮各 3 秒 |

战斗压力三轮为 39.6 / 40.8 / 41.2 FPS，均达到目标。战斗开启特效 p95 为 19.5 ms，超过 33 ms 的帧占 1.4%；压力 p95 为 48.1 ms。p95 表示 95% 帧的耗时不超过该值。连续同强度震屏在 500 ms 内合并，更强命中可以即时打断；伤害结算和飘字保留。

验证环境：2026-10-27（UTC），Linux `6.12.113+deb13-amd64`，Node.js `v24.22.1`，Chrome `156.0.8078.47`。浏览器使用独立临时配置、无界面模式和触屏模拟。战斗性能配置使用 `--disable-gpu`；家园允许 GPU，实际渲染器为 ANGLE / Vulkan / SwiftShader 软件渲染。
