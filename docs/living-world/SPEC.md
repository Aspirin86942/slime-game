# 单地图家园规格 · V5

保留完整家园经营，其余系统以根目录史莱姆-参考.html的规则、数值和界面为准。原版保持手动／自动战斗、探索收益暂存后领取，以及原角色造型、开场和设置。家园采用柔和插画，俯视地面铺满浏览器；建筑通过立面、屋顶、阴影和按纵向落地点排序产生立体感。

## 界面与操作

原陪伴、召唤、探索、背包、成长保留，增加家园入口。默认进入陪伴。家园地图独占窗口，资源、时间、导航和操作面板悬浮在地面上。手机面板从底部展开，桌面面板位于右侧。

全部页面以参考版魔法风为界面基准，共用原版六种主题和线框操作图标。家园顶部保留晶币、积分、等级、设置；顶部栏和底部导航均居中，最大宽度480像素，与原页面保持一致。家园名称合并至季节条，材料单独显示。家园面板采用对应主题的实色弹窗底色；建筑、植物和材料缩略图保留绘本素材。栏位高度实时测量，控件避让安全区；小屏打开面板时隐藏地图工具和资源浮层。

地图36×24格，每格48像素。拖动平移、滚轮/按钮/双指缩放，镜头限制在可覆盖整个视口的范围。建筑点选放置、旋转、拖动移动、收纳和取回；失败不扣材料。道路拖动一次提交一条命令，取消指针操作不提交。键盘可聚焦物件，Enter/空格查看，Escape退出工具。

## 保留的经营

- 24种经营设施、42件装饰及6种路面。已有远征站和共鸣石保留为可移动、可收纳的纪念装饰。
- 55种植物，保留成长、水分、照料、施肥、收获、果树重复产出、育种、品系命名、收藏和复制留种。
- 17条制作配方，队列、等级条件、材料消耗与领取守恒。档案馆可制作星纹遗物，补齐原依赖远行的遗迹碎片来源。
- 首次收获发放一颗发光花种子；旧档已有发光花时不重复发放。发光花成熟后常驻，可移回种子库。
- 18种生态访客，保留光照、湿度、肥力、水质和季节条件。生态属性按同一张地图内的地形计算。
- 史莱姆抚摸、喂食、聊天、小食、休息、工作、聚餐及回忆。玩具区连接旧接球和叠叠乐。料理与药剂可在伙伴面板使用。

## 时间与占用

在线使用一个推进入口：每秒恢复，按保存的12秒周期执行参考版探索，再推进家园一秒。探索收益产生后同步刷新领取入口，基础恢复与饲料只结算一次。离线仅补算植物、制作、生态和岗位，最多12小时；原版体力、饲料和探索奖励保持参考版的离线行为。

家园岗位、旧派遣、战斗和小游戏互斥。已工作的伙伴不参与派遣、合体和战斗；结束工作后恢复可用。生活移动避开建筑，优先道路；建筑移动后重新计算目的地。图形动画不发放收益。

## 迁移

先校验V1–V4，再写入并核验原文备份，最后迁移V5。任一步失败保护原始存档。

旧六区坐标转换为x + (zone % 3) * 12、y + floor(zone / 3) * 12；建筑、植物、居民、道路和路面材质统一为全局坐标。原ID、等级、成长、品系、布局和队列保留。V1/V2无家园布局时使用居中的新家园。

统一库存保留物品来源：旧背包food→feed、旧家园food→ingredient、旧饲料槽→槽内feed、品系种子→对应ID库存。撤回的旅行物资归库，已得晶币结清；容量不足进入待领取库存。重复加载不重新结算。

新版远行、独立故事、关系、共鸣育幼及三款新增小游戏不再启动。未完成故事转归档；幼体、历史关系和旅行原始记录写入world.retired。成年伙伴、记忆、收藏与纪念物保留。旧自动派遣仍按旧核心运行；V4中的队伍预设可恢复，但不会凭空补回已丢失的历史派遣设置。

存储失败时可重试当前结果；跨标签更新暂停本页；未来版本、非法坐标、占地冲突和重复ID拒绝读取。普通刷新释放战斗和小游戏占用，不发胜利奖励。

## 完成标准

经营链可操作、迁移守恒且幂等、旧玩法回归通过。五种目标视口显示全屏地面和可触达按钮；真实鼠标与触屏输入通过。普通场景≥55 FPS、300株植物场景≥30 FPS；记录实际机器和浏览器，不将桌面测量等同手机性能。
