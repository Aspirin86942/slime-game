# 家园操作界面

目标：点建筑后用环绕按钮直接操作，在底部横滑挑选建筑，详情采用毛玻璃面板；升级材料与新形态可见，摆放时看得见建筑。

## 交互约定

- 建造栏从底部展开，设施、装饰、小径、收纳均为横向滑动图卡；支持手机滑动、鼠标拖动和桌面左右箭头。滑动不触发放置，自动刷新保留浏览位置。设施按用途筛选，图卡写明用途和材料。已建造的设施可直接定位，已收纳的设施可直接取出。
- 点建筑展开功能、升级、移动、管理四个环绕按钮，围绕实际建筑图定位；横屏排列在建筑四角。点击功能后打开毛玻璃操作卡。厨房、工坊直接显示各自的配方与队列；饲料槽直接补充；玩具区点选伙伴后启动原小游戏；餐桌默认选中可容纳的空闲伙伴，可点名字调整。
- 环形升级按钮打开新旧形态对照，确认按钮显示费用；操作卡中的升级和移动固定在底部。升级按钮显示下一形态和费用，缺材料、空间不足、满级、旧存档免费展开分别明确提示。伙伴安排与收纳放在「管理」。
- 建造和移动使用实际建筑图作为半透明预览，点击地面或拖动后松手放下。操作栏只有名称、位置提示、旋转和取消。失败保留当前工具；取消不会提交。键盘方向键调整位置，回车放下，Escape 取消。
- 镜头按操作卡的实际尺寸留白，让所选建筑显示在卡片旁边或上方。手机操作卡内容可滚动，底部动作固定。
- 种植栏突出播种，留种、命名与收藏折叠收纳。授粉棚直接显示已开花的亲本图卡，默认选择一对同类植物，玩家可点选调整。
- 制作总览汇总队列并以设施图卡进入配方，避免全部配方混排。六主题、原页面、单文件离线与存档格式沿用现有实现。

家园视图、局部样式和共用移动图标；命令分发返回执行是否成功，界面据此结束摆放。游戏材料、等级、保存与规则仍由原命令校验负责。
